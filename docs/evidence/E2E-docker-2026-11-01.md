# E2E · 真实 Docker 端到端（2026-11-01）

> 目的：证明「Agent 循环 + 确定性策略 + 真实加固容器 + 哈希链审计」在**同一个进程外**完整跑通，而不是 Fake 沙箱的模拟。
> 环境：Windows 11 + Docker Desktop 29.7.2（Linux 容器，cgroup v2）+ Python 3.14.2。
> 命令：`python backend/demo_docker.py`

## 1. 前置

## 3. 结论

- **真实执行**：`python3 main.py` 在加固容器内运行并返回 `exit=0`，不是模拟输出。
- **策略先拦**：`rm -rf /` 被 `D-RM-ROOT` 拒绝，**并未下发到容器**；只有审批通过的 `rm -rf /workspace/tmp` 才执行。
- **外联被拦**：`curl | sh` 被 `D-CURL-PIPE-SH` 拒绝，容器本身也是 `--network=none`。
- **审计可验证**：29 条事件、SHA-256 哈希链 `verify = True`。
- **生命周期干净**：任务结束容器销毁，`docker ps -aq` 计数 0。
- **宿主指纹**：Windows 宿主返回 `source: "unavailable"`（不伪造）；真实 Linux 宿主的 `df -i` / `/etc` 文件数对比在 Vultr sandbox VM 上执行（见 WO-01 / WO-04）。
