## 5. 未覆盖/残余风险

1. 真实 Vultr 双 VM 网络边界、TLS 证书、VPC 防火墙未在云上验证（BLOCKED）。
2. gVisor 未实测；当前 runc 共享宿主内核，内核 0day 仍是理论逃逸面。
3. 策略静态绕过（编码、两段式、Python 内联）仍存在；容器边界兜底，已在文档列明。
4. Trace 锚点/HMAC 与日志同机，不能防御拥有宿主权限的攻击者。
5. 审批/限流是单进程内存实现；多 worker 需外部存储。
6. Docker socket 组权限在 Vultr 上需按实际 GID 配置（本地 Docker Desktop 为 0）。
7. 沙箱镜像未固定 digest；供应链风险仍在。
