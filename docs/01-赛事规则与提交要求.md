- 两条赛道，**只能选一条**：

| | Challenge 1 | Challenge 2 |
|---|---|---|

| 核心 | 沙箱内真实执行代码 / 操作浏览器，containment-first | 企业级多步工作流平台 |
| Vultr VM 后端 | 必须 | 必须 |

| 隔离沙箱 | **必须** | 不要求 |
| 与 YAI Guard | **完全对口，选它** | 不对口，放弃 |

Challenge 1 内部有两种执行模式，可只做一种、也可都做：

- **Pattern A · Sandboxed code execution**：用户提问 → 模型写代码 → 代码在容器内运行 → 真实输出回传 → 模型解释。官方示例方向：CSV Analyst、Prove-It Code Reviewer、Chart Anything、File Fixer、Self-Healing Runner。
- **Pattern B · Sandboxed browser use**：目标 → 规划 → 容器内 Playwright → 截图回传 → vision 模型校验 → 人工审批后执行最终动作。官方示例方向：Comparison Shopper、Form Filler、Site QA Sweep、Research with Receipts、Page Watcher。

> **决策建议（详细论证见 `05-MVP架构设计.md`）**：MVP 锁定 **Pattern A**，把"终端命令 + 文件读写改 + 策略拦截 + 审计"做到真实可演示。Pattern B（浏览器）列为**明确的非目标**——它会把沙箱镜像、egress 控制、vision 调用、审批门的工作量翻倍，5 天内必然两头不靠。赛题原文是"one or both"，只做 A 完全合规。

## 4. Challenge 1 强制技术栈（逐条，含原文口径）

## 8. 评分标准与取胜策略

官方四项，权重未公布：

| 维度 | 官方定义 | YAI Guard 的得分抓手 | 不能踩的坑 |
|---|---|---|---|
| Application of Technology | 模型是否被有效集成进方案 | Vultr Serverless Inference + tool calling 闭环；模型负责规划与解释，**执行由确定性工具完成** | 只把 LLM 当聊天框；或绕过 Vultr 调外部模型 |
| Presentation | 表达的清晰度与效果 | 5 分钟内讲完：问题 → 架构 → 真实执行 → **拦截瞬间** → 审计回溯 | 视频里全是架构图，没有真实执行画面 |
| Business Value | 影响与实践价值 | "让 Agent 能干活但炸不到你"——企业落地 Agent 的第一道门槛；可映射到 CI、数据分析、运维 | 讲成"通用 AI 助手"，价值失焦 |
| Originality | 独特性与创造力 | 把"安全边界"做成**产品的一等公民**：策略可视化、拦截可解释、审计可回放 | 做成又一个"代码解释器"套壳 |

**策略判断**：本赛道的隐含评分锚点是 **containment**。绝大多数参赛队会做出"能跑的 Agent"，但很难做出"**被攻击时优雅地失败并留下证据**"的 Agent。YAI Guard 的差异化应压在：
1. 拦截是**真实内核级/运行时级**发生的（不是关键词过滤假装拦）；
2. 拦截后**宿主机完好**可被当场证明；
3. 全链路**审计日志**可回放、可导出；
4. 策略是**声明式配置**，不是散落在代码里的 if。

## 9. 合规红线（会被判无效或严重扣分）

1. **LLM 调用不得出 Vultr**：Challenge 1 明确要求所有 Agent LLM 调用走 Serverless Inference。任何外部 provider 的 fallback 都是风险。
2. **不得在宿主机/app 进程内执行用户代码**：这是赛道定义本身，违反即失去参赛意义。
3. **不得提交非原创作品**：YAI Guard 必须是独立新仓库，不能把 YAI Agent Core 整体复制包装；可复用其 runtime 接口，但沙箱/策略/执行器必须独立实现。
4. **必须 MIT-compliant**：仓库需带 MIT LICENSE，第三方依赖需兼容 MIT。
5. **Demo 必须公网可用**：localhost 截图不算。
6. **不得用预制动画冒充执行**：视频中的 containment moment 必须是真实运行录屏。
7. **报名必须在 kickoff 前完成**：错过即无法参赛，无补报通道。
8. **不得在未确认前部署收费资源**（本项目内部约束）：预研阶段只做设计，不产生账单。
