## 3. 策略引擎

### 3.1 评估流程（`PolicyEngine.evaluate`）

```
ToolCall
  → 0. 预算/时限（D-BUDGET）
  → 1. 工具白名单（D-UNKNOWN-TOOL）
  → 2. 文件类：路径规范化 → deny 列表 → 读写根校验（D-PATH_*）
  → 3. run_command：
       去引号 → 危险正则（D-*）
       → 逐段 argv：deny 二进制 → rm 结构化检查 → shell -c → 审批二进制/未知二进制
       → 重定向目标必须在 /workspace（D-REDIRECT-OUTSIDE）
       → 域名：内网/元数据拒绝；非白名单要审批
  → 4. 无命中 → ALLOW（A-CMD-ALLOWLISTED）
```

规则优先级：**deny > require_approval > allow**；未知一律 fail-closed。

### 3.2 当前规则覆盖（`default_policy.json`）

- 13 条危险正则：`rm -rf /`、`--no-preserve-root`、fork bomb、写块设备、`chmod 777 /`、`curl|sh`、`base64|sh`、反弹 shell、云元数据、docker.sock、凭证路径、`eval`、`dd of=/dev/`
- 25 个 deny 二进制：`mkfs/mount/dd/sudo/systemctl/nsenter/unshare/docker/nc/...`
- 21 个审批二进制：`rm/mv/chmod/pip/apt/git/curl/wget/...`
- 路径 deny：`/etc/shadow`、`/proc/*/environ`、`~/.ssh/*`、`~/.aws/*`、`.kube/config`
- 网络：默认拒绝；仅 `pypi.org`、`files.pythonhosted.org`、`registry.npmjs.org`

### 3.3 关键设计选择

- **去引号后再匹配**：`sh -c "rm -rf /"` 的边界是引号，只按空白匹配会漏。代价是 `echo "rm -rf /"` 也会被拦——可接受的 fail-closed。
- **`rm` 做结构化检查**：正则覆盖不了 `rm -fr /*`、`rm --recursive /`、`rm -rf ../` 的所有排列，必须解析 argv。
- **不假装策略=安全**：命令可被编码/混淆绕过；真正的保证是容器边界（只读根 + cap-drop + pids/mem + `--network=none`）。这句话要写进 README 与视频口播。

## 4. 审计 Trace

### 4.1 事件与哈希链

- 14 种事件类型（`task.created` … `sandbox.destroyed`），未知类型直接拒绝。
- 每条：`hash = sha256(prev_hash + canonical_json(event 去掉 hash))`，`prev_hash` 首条为 64 个 0。
- `verify()` 从 GENESIS 重算整条链，返回第一个坏事件的 `seq`；`TraceStore` 重启时会先校验再续写，损坏则拒绝启动。
- 脱敏在**哈希之前**执行：`Bearer ***`、`sk-***`、`*KEY=***`，保证 key 不落盘且不破坏链。

### 4.2 已实现的测试

| 用例 | 断言 |
|---|---|
| 追加 3 条 | seq 1,2,3；链校验通过；首条 prev=GENESIS |
| 篡改第 2 条 payload | `verify()` 返回 `(False, 2)` |
| 写入含 key 的 payload | 磁盘无明文、有 `***`、链仍有效 |
| 导出 JSONL | 每行可 `json.loads` |
| 重新打开续写 | seq 连续、链有效 |
| 未知事件类型 | 抛 `ValueError` |

## 5. Agent 循环

`run_agent(task, model, policy, sandbox, trace, task_id, approver, emit)`：

1. 创建沙箱并记录 `sandbox.created`（含 limits、host fingerprint）。
2. 每一步：模型产出 tool_call → `tool.requested` → `policy.evaluate` → `policy.decision`。
3. `deny`：把 `{ok:false, rule, reason, suggestion}` 回灌模型，**不执行**。
4. `require_approval`：`approval.requested` → 等待 approver（默认拒绝）→ `approval.resolved`。
5. `allow`：执行工具 → `sandbox.exec` / `file.changed` → 结果包在 `<sandbox_output>` 里回灌。
6. 结束（`finish` 或模型不再调工具）→ `task.completed`；最后 `finally` 里 `sandbox.destroyed`。
7. 步数/时间超限 → `resource.limit` + `task.failed`。

**默认 aprover 是拒绝**（安全默认）；离线演示与测试显式传入允许函数。

## 6. 三种沙箱后端

| 后端 | 用途 | 是否真实隔离 |
|---|---|---|
| `FakeSandbox` | 单测、无 Docker/无 key 的离线演示 | ❌ 只模拟语义 |
| `DockerSandbox` | 单 VM / sandbox VM 上的真实执行 | ✅ 加固容器（参数见 `build_run_args`） |
| `RemoteSandbox` | 双 VM：app 通过 VPC 调 controller | ✅ 取决于 controller 侧 Docker |

`build_run_args()` 是纯函数，已有 4 个单测断言：`--network=none`、`--read-only`、`--cap-drop=ALL`、`--no-new-privileges`、`--user=65534`、`--pids-limit`、`--memory`、`--cpus`、tmpfs；无 `--privileged`/`--pid=host`/`--network=host`/docker.sock/`-v /`。

**真实加固冒烟已在本地 Docker（Linux 容器，cgroup v2）完成**（2026-10-31，免费，未上云）：

| 检查 | 参数 | 实测结果 |
|---|---|---|
| 只读根 | `--read-only` | `/root_write_test` → `Read-only file system` |
| 工作区可写 | `/workspace` tmpfs | 写入成功 |
| 零网络 | `--network=none` | `wget` 失败（exit 1） |
| 零 capability | `--cap-drop=ALL` | `CapEff: 0000000000000000` |
| 非 root | `--user=65534:65534` | `uid=65534` |
| 禁挂载 | 默认 seccomp | `mount` 被拒 |
| fork bomb | `--pids-limit=64` | `sh: can't fork: Resource temporarily unavailable`，容器退出、无 OOM |
| CPU 限额 | `--cpus=0.5` | `docker stats` 显示 `CPU=50.45%` |

证据：`artifacts/docker-smoke-2026-10-31.txt`（本地文件，已 gitignore）。

**仍待验证**：真实沙箱镜像 `yaiguard/sandbox-py:1.0` 的构建、`rm -rf /` 与 `curl|sh` 的 M1/M3 场景、`runsc` 兼容性——这些在 Vultr VM 上做（Day-1 第一件事）。

## 8. 与 04/05 设计文档的偏差（已确认，均可接受）

| 设计文档 | 实现 | 原因 | 影响 |
|---|---|---|---|
| 策略用 YAML | **JSON** | 零第三方依赖、可离线测；需要时加 `yaml` 可选加载 | 无 |
| `apply_patch` 工具 | 暂不实现；`write_file` 返回 unified diff | 覆盖 P0-5「文件修改 + diff」；补丁工具非必需 | 少一个工具 |
| 前端 Next.js | 单页 HTML + SSE | 去掉 Node 构建，5 天关键路径更短 | 视觉可后续升级 |
| 审批是 P1 | **已实现**（阻塞等待 + API 端点） | 代码量小、演示价值高 | P1-1 提前完成 |
| 每任务 named volume | `/workspace` tmpfs + 可选 deps 卷 | 与 04 §4.1 一致 | 无 |
| trace 存 stdout 原文 | 只存 sha256 + 字节数 | 避免把沙箱数据复制到 L0 | 与 04 §7 一致 |

## 9. 红线：宿主机执行只允许在沙箱层
