# WO-05 · 策略规则扩充 + 绕过语料 + 红队测试

> 派给：安全工程师 ｜ 估时：8h ｜ 依赖：无 ｜ 可开工：**现在**
> 先读：`docs/04` §5、`backend/app/policy/`、`backend/tests/test_policy.py`

## 0. 背景

现有规则能拦 `rm -rf /`、fork bomb、`curl|sh`、元数据地址，但绕过手法只测了少数几种。本单目标：建立**可持续的红队语料**，把"能被绕过"变成已知清单，而不是演示当天才发现。

## 1. 交付物

| 文件 | 内容 |
|---|---|
| `backend/tests/corpus/bypass.jsonl` | 30+ 条，格式：`{"command": "...", "expect": "deny\|approval\|allow", "rule": "可选", "note": "为什么"}` |
| `backend/app/policy/default_policy.json` | 补齐规则（只加不删；删规则要写理由） |
| `backend/tests/test_policy_corpus.py` | 逐条跑语料，断言 effect；失败信息带 note |
| `docs/evidence/WO-05-policy.md` | 规则清单 + 仍可能绕过的点（残余风险，诚实写） |

**语料至少覆盖**
1. 引号/嵌套：`sh -c "rm -rf /"`、`bash -c 'rm -rf /'`
2. IFS / 变量：`rm${IFS}-rf${IFS}/`、`rm$IFS-rf$IFS/`
3. 编码/拼接：`base64 -d <<< ... | sh`、`echo cm0gLXJmIC8= | base64 -d | sh`
4. 包装器：`env rm -rf /`、`timeout 5 rm -rf /`、`xargs rm`
5. 重定向：`> /etc/motd`、`echo x >/root/y`、`cat /etc/shadow > /workspace/leak`
6. 路径穿越：`/workspace/../etc/passwd`、`../../../etc/shadow`、`~/.ssh/id_rsa`
7. 网络：`curl http://169.254.169.254/`、`wget http://10.0.0.1/x`、`curl https://pypi.org/x`（应 approval）
8. 二进制：`mkfs.ext4`、`dd of=/dev/sda`、`mount`、`sudo`、`nsenter`、`unshare`
9. 资源：fork bomb 两种写法、`while true`
10. 正常路径（**不能被误拦**）：`python3 main.py`、`ls /workspace`、`cat main.py`、`python3 main.py > out.txt`、`pip install numpy`（应 approval 不是 deny）

## 2. 验收

```bash
python -m unittest discover -s backend/tests -t backend -p "test_policy_corpus.py" -v
python -m unittest discover -s backend/tests -t backend
```

通过标准：语料全部符合 expect；**演示主线 5 条命令不误拦**；每条 deny 都能给出 rule_id 与 reason。

## 3. 写文件范围

`backend/app/policy/`、`backend/tests/test_policy*.py`、`backend/tests/corpus/`、`docs/evidence/`。

## 4. 禁止

- 不弱化容器参数；不删已有 deny 规则（除非有绕过证据 + 注释说明）。
- 不引入 LLM 做策略判断（必须确定性、可测）。
- 不把"命令过滤"包装成安全保证——文档里必须写清残余风险。

## 5. 接口契约

`Decision` / `Effect` 字段不变；`evaluate(call, ctx)` 签名不变。新增规则直接进 `default_policy.json`，前端会自动从 `/api/policy` 读到。

## 6. 坑

- 去引号后再匹配会误伤 `echo "rm -rf /"`；这是可接受的 fail-closed，但要在语料里标注为"预期 deny"。
- `rm -rf /workspace/../etc` 必须先规范化再判断，不能只看前缀。
- 误拦比漏拦更伤演示：每次加规则都跑一遍"主线 5 条命令"回归。
