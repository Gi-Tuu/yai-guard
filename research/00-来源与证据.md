| ID | 事实 | 归属 | 证据文件 |

| F-04 | 推理计费存在**两套口径**：产品页/支持文档 `$0.55/$2.75 per 1M`，而 live catalog 逐模型 `$0.10–$0.75`；两者同时在线 | 推理 | [`02-inference-证据.md`](02-inference-证据.md) |

| F-06 | gVisor 默认平台 `systrap` **不需要 `/dev/kvm`**；要求 Linux 5.6+；2026-07 起改为多文件安装 | 沙箱 | [`03-sandbox-证据.md`](03-sandbox-证据.md) |
| F-07 | VX1 明确支持 virtualization；官方 sandboxing 指南在 VX1 上要求并验证 `/dev/kvm`（`msb doctor`） | 沙箱/机型 | 同上 |
| F-08 | OpenSandbox 的 Docker runtime **不需要 k8s**；E2B 是托管云沙箱（不满足 "on Vultr"）；Firecracker 依赖 KVM | 沙箱 | 同上 |
| F-09 | 普通 Cloud Compute 是否暴露 `/dev/kvm` **无官方承诺**（按"默认没有"设计，Day-0 实测） | 沙箱 | 同上 |

> 结论：这些补充不改变主方案，但改变了三个执行细节——**要绑卡**、**只能 Destroy 停费**、**推理预算按高值兜底**。
